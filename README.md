
# JavaScript in 30 Days 🚀

A 30-day journey from beginner to advanced JavaScript through practical projects.

## 🎯 Goals

- Build a strong JavaScript foundation
- Practice concepts through real-world projects
- Improve problem-solving skills
- Prepare for full-stack development

## 🗺️ Learning Roadmap

### Beginner JavaScript (Days 1–10)

Variables, data types, functions, scope, callbacks, objects, prototypes, and basic OOP.

### Intermediate JavaScript (Days 11–20)

Array methods, inheritance, classes, error handling, promises, async/await, and data processing.

### Advanced JavaScript Project (Days 21–30)

Advanced concepts, practical systems, asynchronous programming, caching, and application architecture.
