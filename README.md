# JavaScript in 30 Days 🚀

My 30-day journey to learn JavaScript from beginner to advanced.

This repository contains **concept-focused JavaScript code written while learning**. The goal is not to build 30 projects, but to understand JavaScript concepts by implementing them in code.

## 🎯 Goal

Learn JavaScript step by step and build a strong understanding of:

* JavaScript fundamentals
* Data types and variables
* Functions and scope
* Arrays and objects
* DOM manipulation
* Events
* Asynchronous JavaScript
* Promises and Fetch
* APIs
* Object-Oriented JavaScript
* Prototypes
* Closures
* Advanced JavaScript concepts

## 🧠 Learning Approach

The code in this repository is written to **demonstrate JavaScript concepts through practical examples**.

Some programs may become lengthy as more concepts are introduced. That's intentional — the purpose is learning and understanding, not keeping every program as short as possible.
